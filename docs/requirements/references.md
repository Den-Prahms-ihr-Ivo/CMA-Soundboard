# Requirements — Soundboard

## Requirement ID prefix reference

| Prefix           | Module                             | Phase |
| ---------------- | ---------------------------------- | ----- |
| `REQ-AUDIO-xxx`  | Audio mixer, ducking, playback     | A     |
| `REQ-BT-xxx`     | Bluetooth management, device list  | B     |
| `REQ-REMOTE-xxx` | BLE remote communication           | C     |
| `REQ-BMS-xxx`    | Battery management system (remote) | C     |
| `REQ-USB-xxx`    | USB mass storage, file loading     | A/B   |
| `REQ-SYS-xxx`    | System-level, boot, FreeRTOS tasks | All   |
